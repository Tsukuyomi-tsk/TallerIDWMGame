# GameVault UCN

Backend de **GameVault UCN**, una plataforma de distribucion digital de
videojuegos. Taller 1 — API REST (Introduccion al Desarrollo Web y Movil).

> **Estado:** en construccion, fase a fase (ver `feature/*` en el historial
> de commits). Este README se completa en la fase de documentacion final,
> con descripcion, stack, instalacion, variables de entorno, migraciones,
> credenciales del seeder y la coleccion de Postman.
